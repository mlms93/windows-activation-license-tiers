## Windows 激活码购买前必须确认的四件事

### 版本名称里不能有“中文”两个字

“家庭版”和“家庭中文版”不是一回事，专业版同理。买之前先在「设置 > 系统 > 系统信息 > Windows 规格」里看一眼版本名称，如果写的是“Windows 10 家庭中文版”“Windows 11 专业中文版”这类带“中文”的名字，这个激活码用不了，别花冤枉钱。

### 仅限中国地区使用

激活码面向中国市场，人在海外或者要给海外设备激活，不适用。

### 一码一设备，激活后绑定

商品页的条款是激活后绑定设备、不可转移。一个码装家里三台电脑这条路走不通。网上有说法称绑定微软账号后换机能迁移，这与商品页标注不一致，按保守的一方理解，以商品页条款为准，不要当成承诺。

### 每单限购 2 件

刚好主力机加备用机各一台，多了要分单。

硬件门槛也顺手确认一下：TPM 2.0、UEFI 且支持 Secure Boot、1GHz 以上双核 64 位处理器、4GB 内存、64GB 存储、DirectX 12 显卡。老机器先跑一遍兼容性检查，别等买完才发现装不上。
